# DPGA-Former
DPGA-Former: Detail-Preserving and Geometry-Aware Semantic Segmentation for VHR Remote Sensing Imagery

## Datasets

We evaluate DPGA-Former on three public benchmark datasets:

- [ISPRS Potsdam](https://www.isprs.org/resources/datasets/benchmarks/UrbanSemLab/Default.aspx) - 5cm GSD aerial imagery, 6 classes
- [LCAI (LandCover.ai)](https://landcover.ai.linuxpolska.com) - Aerial imagery, 4 classes (buildings, woodlands, water, roads)
- [FGID](https://doi.org/10.1109/IGARSS.2018.8518389) - Gaofen-2 satellite imagery, 6 classes

---

## Data Splits

Our train/val/test splits for all three datasets are available on IEEE DataPort:

[![DOI](https://img.shields.io/badge/DOI-10.21227/16vt--b551-blue)](https://doi.org/10.21227/16vt-b551)

**DOI: 10.21227/16vt-b551**

The package includes:
- ISPRS Potsdam: Official splits (train: 17 images, val: 7 images, test: 14 images)
- LCAI: 5:2:3 random splits with fixed random seed
- FGID: Scene-level 5:2:3 splits
